# mod-worgoblin-high-elf
## F-103_mod-skyborne-alliance

### Features
- Playable Skyborne (Alliance)
    - Forever model and customization only in the 256-bit version (WHE-256-bit with the wowdecomp-256-bit client and azerothcore-wotlk-256-bit)
    - Shows the native model from Kalibro's races package: 5 skin colours x 26 eye colours, 10 faces, 25 (male) / 29 (female) hair styles each with or without feathers, 32 hair colours, and beard x eyebrows (male) / eyebrows (female) as facial styles
    - Home: Human (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Blood Elf (names, and the voice lines Forever lacks)
    - Helmet prefix 'Be'
- Generated by WHE-256-bit's `tools/races/skyborne_modpaks.py` (tentative, for testing)
- Voice: Forever's emotes, error lines and combat sounds (`tools/races/retail_voices.py`; files in WHE-common `Sound/character`), the Kin race's where Forever has none

### Requirements
- The client assets in WHE-common (`custom/skyborne`)
- Interface: race button and the ALLIANCESKYBORNE entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Known Issues
- Tentative: not tested in game yet
- No racial abilities yet
- No racial mount
- Placeholder racial faction name and description
- Native look: one feather colour (Seafoam), Long ears, no horns, blindfolds, tattoos or jewelry, and only 26 of the 47 eye colours (Kalibro's bake); the 130 skin colours make that slider long
