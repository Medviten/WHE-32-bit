# mod-worgoblin-high-elf
## F-050_mod-playable-northrend-skeleton

### Features
- Playable Northrend Skeletons (Horde), male only
    - Stock 3.3.5 model and customization (the NPC race rows F-008 moves to 180)
    - Home: Undead (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Undead (voice, emotes and names, copied at build time)
    - Helmet prefix 'Sc'
- Generated by `tools/races/new_race_modpaks.py` (tentative, for testing)

### Requirements
- Interface: a race button and the NORTHRENDSKELETON entries in `CharacterCreate.lua`, `GlueParent.lua` and `GlueStrings.lua`

### Known Issues
- Tentative: not tested in game yet
- No racial abilities yet
- No racial mount
- Placeholder race icon, racial faction name and description
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size
- Male only: female characters use the male model and customization (F-026's `patches/core/male-only-races.patch` creates them male)
