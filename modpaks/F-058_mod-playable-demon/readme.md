# mod-worgoblin-high-elf
## F-058_mod-playable-demon

### Features
- Playable Demons (Horde), male only
    - WallCraft's playable Demon model (Vanilla format, converted with m2_256_to_264.py) and its skin textures (no customization rows: skin colour only)
    - Home: BloodElf (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: BloodElf (voice, emotes and names, copied at build time)
    - Helmet prefix 'Be'
- Generated by `tools/races/new_race_modpaks.py` (tentative, for testing)

### Requirements
- Interface: a race button and the DEMON entries in `CharacterCreate.lua`, `GlueParent.lua` and `GlueStrings.lua`

### Known Issues
- Tentative: not tested in game yet
- No racial abilities yet
- No racial mount
- Placeholder race icon, racial faction name and description
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size
- Male only: female characters use the male model and customization (F-026's `patches/core/male-only-races.patch` creates them male)
- Converted Vanilla model: armour may composite oddly (try adding the race to `creatureSkinRaces`)
