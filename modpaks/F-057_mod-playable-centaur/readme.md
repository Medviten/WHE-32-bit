# mod-worgoblin-high-elf
## F-057_mod-playable-centaur

### Features
- Playable Centaur (Horde)
    - CoA Custom 1.9 model and textures (Ilusixn's CoA race files, CoA race 102), prepared by `tools/models/coa_race_prep.py`
    - Customization: the 16/16 skin colours of CoA's appearance catalog (`EsteriaCentaur.bin`); its other options (EsteriaAppearance.dll) are fixed at their first choice
    - Home: Tauren (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Tauren (voice, emotes and names, copied at build time)
    - Helmet prefix 'Ta' (CoA's)
    - Model size and display scale from CoA's CreatureModelData/CreatureDisplayInfo rows
- Generated by `tools/races/coa_race_modpaks.py` (tentative, for testing)

### Requirements
- Client files from `tools/models/coa_race_prep.py` (in WHE-common's `patch-A.MPQ`)
- Custom client with `creatureSkinRaces` containing the race ID: the skin texture is composited whole and armour textures are not drawn on it
- Interface: race button and the CENTAUR entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size
- CoA's extra appearance options (EsteriaAppearance.dll) are not available

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA race 100 (Centaur), renumbered; blocks at the end of `[BASE,F-057]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Plains Charge: Increases your haste by 10% for 10 sec.
    - Gallop: Break into a full gallop, increasing your run speed by 100%. Takes as long to summon as a mount, cannot be used in combat and can be dismissed like a mount.
      (CoA drives it with the C++ scripts spell_centaur_gallop/_aura, which WHE does not have: without them it is a plain speed buff)
