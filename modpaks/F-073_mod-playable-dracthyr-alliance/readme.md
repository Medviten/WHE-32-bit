# mod-worgoblin-high-elf
## F-073_mod-playable-dracthyr-alliance

### Features
- Playable Dracthyr (Alliance)
    - Retail model and customization only in the 256-bit version (WHE-256-bit with the wowdecomp-256-bit client and azerothcore-wotlk-256-bit)
    - Shows the Human model and customization rows
    - Home: Human (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Human (voice, emotes and names, copied at build time)
    - Helmet prefix 'Hu'
- Generated by `tools/races/dracthyr_modpaks.py` (tentative, for testing)

### Requirements
- Interface: race button and the ALLIANCEDRACTHYR entries in `CharacterCreate.lua/.xml`, `GlueParent.lua` and `GlueStrings.lua`

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon
- No in-world form toggle yet (Visage): the form chosen in the character creator stays
- Soar flies with the stock flight rules; no Skyriding
- Model size and collision are the Human model's

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA race 54 (Dracthyr (Alliance)), renumbered; blocks at the end of `[BASE,F-073]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Wing Buffet: Stuns up to $i enemies within $a1 yds for $d.
    - Soar: Escape the effects of any immobilization or movement speed reduction effect and become immune to them for $81001d.
    - Draconic Mind: Intellect increased by $s1%.
    - Scales of the Aspects: Reduces the damage taken by spells by $s1%.
