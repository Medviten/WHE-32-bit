# mod-worgoblin-high-elf
## F-096_mod-playable-cultist

### Features
- Playable Cultists (Horde)
    - Stock human model, with one skin colour from the Alpha-Worgen package; stock human hair and facial hair
    - Home: Undead (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Human (voice, emotes and names, copied at build time)
    - Helmet prefix 'Hu'
- Generated by `tools/races/alpha_race_modpaks.py` (tentative, for testing)

### Requirements
- Interface: a race button and the CULTIST entries in `CharacterCreate.lua`, `GlueParent.lua` and `GlueStrings.lua`

### Known Issues
- Tentative: not tested in game yet
- No racial abilities yet
- No racial mount
- Placeholder race icon, racial faction name and description
- Barber shop styles have generic names
- No `HelmetGeosetVisData` rows, so hair is not hidden under helmets
- The race button and strings are only in the 256-bit version's glue files so far
