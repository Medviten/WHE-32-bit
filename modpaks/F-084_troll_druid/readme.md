# mod-worgoblin-high-elf
## F-084_troll_druid

### Features
- Playable Troll druids (as in Cataclysm), without the rest of ARAC
    - Starting outfit, start location (Valley of Trials), action bars
    - Druid weapon skills (Maces, Daggers) opened to Trolls
- Cataclysm Troll druid forms:
    - Cat and bear forms in five colors each, following hair color
    - Tree of Life (orange), Moonkin (red owlbear), Flight and Swift Flight forms
    - Travel form: F-011's Horde default when F-011 is enabled, otherwise the stock one

### Known Issues
- None

### Considerations
- Compatible with F-002_mod-arac, which adds Troll druids along with every other combination (but not their forms).
- The forms need the client's druid form models and textures (patch-A).
