# mod-worgoblin-high-elf
## F-047_mod-playable-fel-orc

### Features
- Playable Fel Orcs (Horde)
    - Stock 3.3.5 model and customization (the NPC race rows F-008 moves to 172)
    - Home: Orc (classes, start position, start outfits, action bars, stats, totems, druid forms, race-restricted
      quests and items)
    - Kin: Orc (voice, emotes and names, copied at build time)
    - Helmet prefix 'Or'
- Generated by `tools/races/new_race_modpaks.py` (tentative, for testing)

### Requirements
- Interface: a race button and the FELORC entries in `CharacterCreate.lua`, `GlueParent.lua` and `GlueStrings.lua`

### Known Issues
- Tentative: not tested in game yet
- No racial mount
- Placeholder race icon, racial faction name and description
- Barber shop styles have generic names
- Character creation camera is not tuned for the model's size

### CoA Custom 1.9 racials
- Active: learned with the racial skill line
- From CoA race 23 (Fel Orc), renumbered; blocks at the end of `[BASE,F-047]_spell.sql`, `_skilllineability.sql` and `_spellicon.sql`
    - Fel Rage: Increases your attack power by $s1 and your spell power by $s2. Lasts $d. Cannot be used while offensive effects from trinkets are active.
    - Demonic Endurance: Duration of Stun effects reduced by an additional $s1%.
    - Fel-Hardened: Reduces the damage taken by Shadow spells by $s1%.
    - Axe of the Horde: Expertise with with Fist Weapons, Axes and Two-Handed Axes increased by $s1.
